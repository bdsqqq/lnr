## Codebase Patterns
(from phase 1)

- zod schemas use `.meta({ positional: true })` for positional args
- `.describe("...")` contains flag descriptions
- `.optional()` presence determines required status
- router procedures define command metadata via `.meta({ description, aliases })`
- Business logic (resolvers) belongs in core package where @linear/sdk is available
- CLI package consumes core exports, doesn't import SDK directly
- Generated schemas must use `export const` not re-export to avoid TS2323 redeclaration errors
- Linear SDK team reference can be undefined - must add null check before accessing .id
- Wiring is minimal: just swap the router import in index.ts
- Contract tests verify schema shape, not implementation details
