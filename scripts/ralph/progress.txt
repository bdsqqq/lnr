## Codebase Patterns
- entity config in packages/codegen/entity-config.ts controls extraction
- introspection in packages/codegen/introspect-linear.ts fetches types
- commands generated in packages/codegen/generate-commands.ts
- core logic in packages/core/, CLI presentation in packages/cli/
- scoped entities use flags on parent commands (ADR-0004 pattern)
- run `bun run check` before shipping
- templates accessed via team.templates() in Linear SDK
- read-only entities don't need full CRUD generator, hand-craft simpler commands
